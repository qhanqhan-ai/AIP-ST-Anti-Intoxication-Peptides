# Peptide Classification and Self-training Evidence Package

This directory is a reviewer-facing package for the peptide classification workflow.

## Project Summary

The workflow starts from a cleaned raw peptide dataset, performs rule-based peptide data augmentation, filters augmented peptides by molecular docking, trains traditional machine-learning baselines and deep learning classifiers under a consistent evaluation protocol, selects a Transformer model, and applies self-training on 10 million randomly generated peptide sequences. The final self-trained Transformer model is used for peptide inference, producing `results/final_predictions.csv`.

## Key Files

### Data

- `data/raw_preaugmentation_clean01_plus_class3_class5.jsonl`
  Cleaned pre-augmentation peptide dataset used before label harmonization, class re-mapping, and data augmentation. Original source labels were re-mapped to the four manuscript classes before model training. The final class labels used in the manuscript are Class 0, Class 1, Class 2, and Class 3.

- `data/docking_filtered_base_train_3528.jsonl`
  Dataset after rule-based augmentation and molecular docking filtering. This is the docking-filtered base training set.

- `data/self_training_plus_3000_per_class_deduplicated.jsonl`
  Self-training dataset after adding 3000 high-confidence samples per class and deduplication (15,528 samples total).

- `data/final_inference_input.fasta`
  Final FASTA input used for the final prediction step.

- `data/dataset_statistics.tsv`
  Machine-readable class distributions for the main datasets.

### Results

- `results/model_metrics_summary.csv`
  Model comparison metrics (5-seed mean ± std): overall accuracy, macro precision/recall/F1, and per-class precision/recall/F1 for all four classes.

- `results/model_summary_macro_f1_class3_precision.csv`
  Summary table of Macro-F1, Class 3 precision, and Class 3 AP for model selection.

- `results/class3_ap_values.json`
  Class 3 average precision (AP) values computed from real model predictions for all six models.

- `results/final_predictions.csv`
  Final prediction result generated by the self-trained Transformer model.
  
### Scripts

#### Data Preparation

- `scripts/augment_to_1508_unique.py`
  Rule-based peptide data augmentation script.

- `scripts/delete_augmentation_invalid_peptides.py`
  Invalid peptide filtering script.

- `scripts/xlsx_to_fasta.py`
  XLSX-to-FASTA conversion utility for docking input preparation.

#### Self-training

- `scripts/selftrain_generate_random_peptides.py`
  Generate random peptide sequences (used to create 10 million random peptides).

- `scripts/selftrain_infer.py`
  Run inference on random peptides using the selected Transformer model.

- `scripts/selftrain_filter_by_confidence.py`
  Filter predictions by confidence threshold (>= 0.90) per class with reservoir sampling.

- `scripts/selftrain_filter_merge_dedup.py`
  Combined pipeline: filter high-confidence predictions per class, merge with existing training data, and deduplicate.

- `scripts/selftrain_deduplicate.py`
  Deduplicate JSONL records by peptide sequence.

#### Visualization

- `scripts/plot_final_model_comparison_600px.py`
  Recreates the final 600 px model comparison plot from the included metrics table.

- `scripts/plot_pareto_f1_class3_precision.py`
  Recreates the Pareto-style model selection plot.

- `scripts/export_metrics_and_plot_class3_pr.py`
  Exports summary metrics from the included five-seed table and redraws the Class 3 PR curve from embedded AP values.
